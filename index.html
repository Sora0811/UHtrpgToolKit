UH TRPG Tool Library

Web-based small tools for UH TRPG players and GMs. Each tool runs independently.

Tools

  • Example Tool — minimal starter tool demonstrating the library structure.
  • 購買計算器 — 屬性、技能、資源、專長與造物計算（公式待補）。

No game rules or formulas are defined by this library itself; each tool ships its own requirements.
