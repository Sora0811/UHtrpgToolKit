# 購買計算器 — 使用手冊

## 概述
計算 UH TRPG 中各項目的購買/經驗消耗。

## 功能
- **屬性**：0–99，XP/點數模式切換，0→1 與 1→2 花費相同
- **技能**：0–15，0→1=3XP，1→2=1XP，其餘 (等級−1)×2
- **資源**：支線字串輸入，XP = 等級²×4 + 等級×6 + 點數/400（無條件進位）
- **專長**：等級×3 或 ×6（團隊）
- **造物**：支線字串，紙張=ceil(支線×點數/100)，材料=ceil(點數/3)，DC=ceil(支線×點數/100)

## 支線系統
D=1, C=3, B=9, A=27, AA=54, AAA=81, S=243（3×A）
雙支線 = 2×單支線

## 檔案
- `index.html` — 頁面結構
- `script.js` — 計算邏輯
- `style.css` — 樣式
