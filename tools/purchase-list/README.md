# 購買清單 — 使用手冊

## 概述
記錄預計購買項目，計算所需支線、分數與經驗，並支援多方案比較。

## 支線系統
- D=1, C=3, B=9, A=27, S=81（3×A）
- 雙支線 = 2×單支線（DD=2, CC=6, BB=18, AA=54）
- 支線字串解析：從左到右貪婪匹配（AAA > AA > A）
- 轉換規則：3個D=C, 3個C=B, 3個B=A, 3個A=S

## 功能
- **目前擁有**：輸入支線字串、分數、XP
- **預計購買項目**：分類（下拉選單）、項目、購買目標、支線、分數、XP
- **小計**：顯示剩餘/缺少的支線、分數、XP
- **餘額狀態**：餘額充足 / 餘額不足（顯示還缺多少）
- **購買分支**：儲存多個購買方案，方便比較與評估
- **剪貼簿匯出**：一鍵複製格式化文字

## 資料持久化
- localStorage 儲存，關閉瀏覽器不會消失
- 儲存鍵：`purchase-list`（項目）、`purchase-own`（擁有）、`purchase-branches`（分支）

## 檔案
- `index.html` — 頁面結構與分頁
- `script.js` — 計算邏輯、localStorage、剪貼簿
- `style.css` — 樣式
